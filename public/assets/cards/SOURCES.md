# Tarot card image sources

The 22 Major Arcana images in this directory are local web-sized copies of the
“Pam-A / TaionWC” Rider–Waite–Smith Tarot scans hosted by Wikimedia Commons.

- Artist: Pamela Colman Smith
- Work: Rider–Waite–Smith Tarot (1910)
- Source collection: https://commons.wikimedia.org/wiki/Category:Rider-Waite-Smith_tarot_deck_(TaionWC)
- Rights status: Public Domain Mark 1.0
- Rights statement: https://creativecommons.org/publicdomain/mark/1.0/

Files were retrieved through the official Wikimedia Commons MediaWiki
`imageinfo` API as web-sized thumbnails. The original Commons filenames follow
the pattern `RWS Tarot 00 Fool.jpg` through `RWS Tarot 21 World.jpg`.
